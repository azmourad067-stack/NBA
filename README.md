# NBA Quant Engine

Collecteur NBA DunkAPI → Supabase, tableau de bord Streamlit et moteur prédictif pré-match.
Le code se trouve dans `NBA-Quant-Engine-feature-streamlit-dashboard - Copie/` (voir son README).

## Déploiement Streamlit Community Cloud

- Main file path : `streamlit_app.py` (à la racine du dépôt)
- Dépendances : `requirements.txt` à la racine (installé automatiquement)
- Python : 3.12 ou 3.13
- Secrets : `APP_ACCESS_PASSWORD`, `SUPABASE_DB_URL`, `DUNKAPI_API_KEY`, `NBA_DB_SCHEMA` (voir le README du sous-projet)
